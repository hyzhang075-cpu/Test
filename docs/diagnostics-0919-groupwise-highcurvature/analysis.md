# direct=0 end5cm groupwise high-curvature diagnosis

本报告只读检查现有参数包、静态 score 结果和动态 pickle；未修改生产代码、参数包或旧结果，未运行优化。

## 结论先行

direct=0 点21/22的静态 base_magnitude 没有覆盖 35/45 m⁻¹ 高档，但对应 group1/group2 weights 在这些档位接近 5.0 上界；高档参数因此是边界外推，不是由点21/22高曲率静态样本识别出的增益。动态回放中点21进入 57–65 m⁻¹，点22自身最高约 34.2 m⁻¹，但两者都会落入由静态外推形成的高档权重区。

仅调整 thresholds 不足：它只能改变动态帧落入哪个档位，不能把已经接近 5.0 的高曲率档增益变成接近 1；若把阈值推高到动态峰值以上，则会得到旧档/低档的另一种外推，且会损失明确的曲率分级语义。

建议：

- 阈值可先保持现有 `[0.8, 1.2, 2.0, 3.0, 4.0, 10.0, 20.0, 35.0, 45.0]`，避免用阈值变化掩盖增益回归问题。
- 若下一轮确实要重排高曲率过渡，建议试验阈值 `[0.8, 1.2, 2.0, 3.0, 4.0, 10.0, 20.0, 30.0, 45.0]`；这是实验设计建议，不代表已有数据已经验证该阈值。
- 对 group1/group2 的 35 和 45 m⁻¹ 档增加高曲率锚定/正则，使有效 weight 向 1 回归；推荐先将这四个参数约束在 [0.8, 1.2]，再用动态锚点验证。
- 若必须减少静态外推，可把 35/45 m⁻¹ 作为单一高曲率档（建议过渡中心约 30–35 m⁻¹），但仍需要 weight=1 约束；只改阈值不足。
